# 國二英文互動練習站 (Unit 3・Unit 4・Review 2)

將國二英文 **Unit 3 (226題)**、**Unit 4 (208題)** 與 **Review 2 (8題)** 共 **442 題**完整題庫與詳解，整理為互動式線上練習網站。

## 核心功能

1. **即時作答回饋**：學生每做完一題（選擇題、克漏字題組、文意字彙填空），立即批改並顯示正確答案與完整中文解析／語譯。
2. **U3・U4・Review 2 混合出題（每回約 40 題）**：自動從三個單元均衡混合抽題；克漏字題組會保持完整文章與連號小題一起出現，方便閱讀作答。
3. **智能不重複抽題**：系統自動記錄已練習過的題目 ID，每一回練習都不會重複出題，直到 442 題題庫全部練習完畢才會自動開啟下一輪。
4. **錯題複習專區**：所有答錯的題目會自動收錄至「錯題專區」，記錄累計答錯次數與上次錯誤答案，學生可隨時進入錯題區啟動「錯題重練」，答對後自動從錯題本移除。
5. **題庫總覽與關鍵字搜尋**：可依單元、題型、是否已練習過進行篩選與全文檢索。
